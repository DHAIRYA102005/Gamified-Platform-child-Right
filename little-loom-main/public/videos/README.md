# Video Directory

Place your background video file here.

## Video Requirements

- **File Name**: `hero-background.mp4` (required)
- **Optional**: `hero-background.webm` (for better browser compatibility)
- **Recommended Format**: MP4 (H.264 codec)
- **Recommended Resolution**: 1920x1080 (Full HD) or higher
- **Recommended Duration**: 10-30 seconds (will loop automatically)
- **File Size**: Keep under 10MB for optimal loading

## Supported Formats

- MP4 (primary)
- WebM (optional, for better compression)

## Usage

The video will automatically:
- Play on page load
- Loop continuously
- Be muted (for autoplay compatibility)
- Cover the full screen background

## Tips

1. Use a video that's not too busy so text overlay remains readable
2. Consider adding a subtle overlay in the video itself for better text contrast
3. Compress your video to reduce file size while maintaining quality
4. Test on mobile devices to ensure good performance
